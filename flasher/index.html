Minidisp Flasher

PC status display firmware for ESP32 touch screens.
Plug in your device, pick it below, and click Install.

CYD 2.8" (ESP32-2432S028R)

Cheap Yellow Display, ILI9341 320x240, resistive touch, CH340 USB.

CYD 2.8" v3 (ST7789 panel)

Same board with an ST7789 panel — use this if the standard CYD build shows garbled or inverted colors.

ESP32-C6 Touch LCD 1.47"

Waveshare, ST7789 172x320, capacitive touch, native USB. (Bring-up pending.)

ESP32-1732S019 1.9"

ST7789 170x320 on ESP32-S3, no touch. (Bring-up pending.)
Notes
  • Works in Chrome or Edge (Web Serial API). Safari and mobile browsers are not supported.
  • CYD boards need the CH340 driver installed before the COM port appears.
  • If connecting fails, hold the BOOT button while clicking Install, then release it.
  • After flashing, run the Minidisp Companion app on your PC — the display connects automatically.
  • Buttons stay greyed out until firmware binaries are staged with python firmware/scripts/release.py.
